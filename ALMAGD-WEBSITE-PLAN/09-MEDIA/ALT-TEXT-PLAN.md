## التحرير

جملة قصيرة تصف الظاهر وتحدد المنشأة أو الصنف المؤكد. لا keyword stuffing أو«الأفخم» أو halal منشكلالطعام. مستهدف≤125 حرفاً إرشادي وليس حداً معيارياً؛التفصيلفي caption. الأصلأوال crop يتغيرقديتطلب alt مختلفاً.

الصورة كرابط وحيد تحتاج معنى الوجهة؛يفضل link نصي مستقل مع alt وصفي. Pure decoration فقط alt فارغ؛صورةالمنشأة دليل وليست زخرفة. Logo اسم ALMAGD دون وصفألوان. لا وجوه بأسماء ضيوف دون إذن.

## workflow وقبول

رؤية original/crop → ربط venue/type و fact → ID copy → EN/AR review → screenreader → approval مع rights. صورةتظهرجزءاًمنغرفةلا تثبتعددأسرّتها.

كل content image لها alt مراجَع،والعربيةواتجاه Latin سليمان،ولا PLACEHOLDER أو claim محجوب في alt. لا نسخ alt/caption من OTA دونحقنص. النتائجالآن DRAFT،لأنالأصوللمتصل.
