# خطة الفيديو

P1 اختياري DEC-022؛لا videoP0 ولا أصلأُنشئ. لاتبدأ feature قبلالصور والحقوق وميزانيةالأداء.

| الاستخدام | المواصفة | بوابة |
|---|---|---|
| Home desktop hero |≤12s،≤2.5MB،muted |≥1024،poster LCP،لا Save-Data/slow/reduced-motion |
| venue clip |user-initiated بعدقرار P1 |حقوق و caption وملخصنصي |
| mobile |poster image |لا auto-video |
| YouTube مستقبلي |رابط أو facade اختياري |لا embed initial |

## تصور اللقطات

ثلاثلقطاتقصيرة مقترحة:محيطمنشأةحقيقي،غرفةمننوعمعتمد،وطعامفعلي. Montage لايوحيبأن Cafe والإقامتين متجاورة أو في بناء واحد؛يُعرّفكل venue. لا text داخل الفيديو يصعب ترجمته،ولاسماءمعدلةأو Drone دونتصريح.

## الأداء والوصول

poster عنصر LCP وصورتهبأولوية،video لاحق لا CLS. pause واضح 44 للحركةالتلقائية؛لا audio. المعلومات المهمةفيالنص،والـ clips الناطقةلها captions/transcript مراجَعة.

قدلاتتاح مؤشرات Save-Data/network بكل المتصفحات؛default image-only عندغيابالتحقق خيارمحافظ،لا وعدكشفشامل. حجم ملف الفيديو يقاس بعد الضغط ولا يُستنتج من المدة.

قبول P1:حقوقو release،وجود pause واحترام motion gates،تقريرتحميل D/M،وعدمإفساد CWV. الملفلايفعل feature بمجردوجوده.
