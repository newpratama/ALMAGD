## Cross-sell rules
- Property pages end with "Also in The ALMAGD Collection" (2 cards: the other stay + NJD Cafe).
- NJD Cafe page shows "Stay nearby" with both properties.
- Gallery images link to their venue page ("View Villa NJD").

## Anchor text rules
- Descriptive: "See Villa NJD rooms", "View the NJD Cafe menu" — never "click here".
- Use venue names exactly per DEC-004.
- Same destination → consistent anchor text per locale.
- External links (OTA, Maps, social) get external icon + visually hidden "(opens in new tab)".
