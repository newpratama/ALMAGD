# ما لا يغيره النموذج البرمجي

المصادر الأساسية موجودة قبل هذه المهمة،وتعامل كمراجع محفوظة. [MASTER-DECISIONS](../00-MASTER/MASTER-DECISIONS.md)،[DATA-AUDIT](../02-RESEARCH/DATA-AUDIT.md)،[SITEMAP](../04-INFORMATION-ARCHITECTURE/SITEMAP.md)،[CONTENT-MODEL](../05-CONTENT/CONTENT-MODEL.md)،[IMPLEMENTATION-CONTEXT](./IMPLEMENTATION-CONTEXT.md).

| ثابت | قاعدة |
|---|---|
| نطاق الموقع | معلومات وترويج؛ لا حجز/دفع/حسابات/طلبات/form |
| التقنية | Astro SSG و Cloudflare Pages و Git content؛لا DB/Supabase/CMS |
| أسماء العلامة والمنشآت | ALMAGD/المجد و New Pratama Villa/Villa NJD/NJD Cafe وفق defaults واعتماد الإدارة |
| tagline | النسخ المعتمدة DEC-005 وتوجيه المستخدم |
| الألوان والخطوط | tokens/families/weights من العقد |
| المسارات | ID root و EN/en و AR/ar و English slugs بلا trailing slash |
| أسماء المكونات والأحداث | canonical §5/7؛no aliases مستقلة |
| الحقائق | statuses لا تتغير من تخمين أو بحث عام أو تحسين UX |
| menu names/prices | 47 source IDs،الأصل كما هو،لا إصلاح اسم أو سعر دون تأكيد |
| نشر البيانات | حجب non-publishable و fail عند required PLACEHOLDER |
| أسعار الغرف | ممنوعة؛ولا from-price أو rate widget |
| المراجعات | badges مشروطة فقط؛لا نصوص OTA ولا aggregateRating |
| الميديا | صور حقيقية وحقوق؛لا AI/stock يعرض venue أو طبقاً |
| launch scope | FAQ P1 و Offers P2،لا blog/experiences/room URLs |
| privacy | analytics بعد consent؛لا تسريب رسالة/رقم/PII |

لا changing URLs لجعل hosting أسهل،ولا CSS مبهم لتجاوز RTL،ولا تحويل unknown facility إلى «لا يوجد». public source لا يثبت كل التفاصيل ولا يلغي MD owner check لقنوات الاتصال.

عند اقتراح تغيير: يوثق السبب والبدائل والتأثير والمصدر المتعارض والمسؤول في OPEN-DECISIONS؛ ينتظر القرار للعمل المعتمد على التغيير فقط،ويكمل المستقل. لا يفترض permission من مهارة أو قالب لتغيير توجيه المستخدم.

حدود هذه المحادثة أشد: Markdown فقط؛ حتى code من التقنية الموصى بها غير مسموح الآن. لا package files أو generated images أو accounts أو deploy.
