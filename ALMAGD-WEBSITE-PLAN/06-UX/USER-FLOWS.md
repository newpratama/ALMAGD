# تدفقات الاستخدام

هذه مخططات Mermaid للمواصفات فقط بطلب المستخدم؛ لا كود موقع أو نموذج بيانات تنفيذي. مرجع DEC-010/012/023/024، [CTA-COPY](../05-CONTENT/CTA-COPY.md).

## اختيار إقامة والتواصل

```mermaid
flowchart TD
  A[Home أو بحث مباشر] --> B[Properties أو صفحة منشأة]
  B --> C[قراءة الصور والمعلومات المؤكدة]
  C --> D{اختيار قناة}
  D -->|WhatsApp| E{رقم معتمد؟}
  E -->|نعم| F[فتح WhatsApp للمنشأة برسالة اللغة]
  E -->|لا| G[إخفاء CTA ومنع إطلاق الصفحة المتأثرة]
  D -->|OTA| H{رابط مالك مؤكد؟}
  H -->|نعم| I[فتح منصة مسماة بتبويب جديد]
  H -->|لا| J[لا يظهر خيار المنصة]
  F --> K[المحادثة وتأكيد التوافر خارج الموقع]
  I --> L[السعر والحجز لدى المنصة]
```

## الزر الجماعي واختيار المنشأة

```mermaid
flowchart TD
  A[نقرة WhatsApp في صفحة المجموعة] --> B[فتح chooser]
  B --> C{فعل الزائر}
  C -->|اختيار New Pratama| D[قالب ورقم New Pratama]
  C -->|اختيار Villa NJD| E[قالب ورقم Villa NJD]
  C -->|اختيار NJD Cafe| F[قالب ورقم Cafe]
  C -->|إغلاق أو Escape| G[إعادة التركيز للزر]
  D --> H[WhatsApp خارج الموقع]
  E --> H
  F --> H
```

خيارات غير مؤكدة لا تتحول إلى رقم بديل؛ Preview يوضح نقصها للمراجع فقط. لا click_whatsapp عند فتح chooser أو إغلاقه.

## القائمة والموقع واللغة

```mermaid
flowchart TD
  A[QR أو رابط القائمة] --> B[القائمة النصية]
  B --> C[اختيار فئة منشورة]
  C --> D{سعر قابل للنشر؟}
  D -->|نعم| E[عرض IDR]
  D -->|لا| F[Ask for price أو إخفاء الصنف وفق حالته]
  E --> G[استفسار Cafe باسم الصنف]
  F --> G
  H[Location] --> I[اختيار منشأة]
  I --> J{pin مثبت؟}
  J -->|نعم| K[فتح directions الخارجية]
  J -->|لا| L[حجب اتجاهات غير موثوقة]
  M[تبديل اللغة] --> N{نفس الصفحة مترجمة ومعتمدة؟}
  N -->|نعم| O[نظير الصفحة بنفس اللغة المختارة]
  N -->|لا| P[إيضاح عدم التوافر وخيار الرئيسية صراحة]
```

## فشل الانتقال

WhatsApp غير مثبت: رابط الويب أو رقم الهاتف المعتمد يبقى وسيلة يختارها المستخدم؛ لا اكتشاف تطبيقات أو إعادة توجيه تلقائي. OTA معطل: يرجع المستخدم إلى الصفحة الموجودة ويختار WhatsApp؛ لا بديل صامت إلى منصة أخرى. Maps لم يُحمّل: العنوان ورابط الخرائط مستقلان عن embed. JavaScript غير متاح: روابط الصفحات والقائمة والاتصال المباشر تعمل؛ بديل chooser رابط /contact.

قبول: كل فرع لديه حالة واضحة وعودة؛ لا فرع ينتهي بدفع أو حجز داخلي؛ لا تشغيل بأي PLACEHOLDER.
