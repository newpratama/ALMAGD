# استراتيجية تجربة المستخدم

مرجع DEC-001/008/010/019/023/024/027، [USER-NEEDS](../01-DISCOVERY/USER-NEEDS.md). الهدف أن يفهم الضيف المجموعة ويختار وجهة ثم يصل إلى قناة مناسبة. التحويل نقرة تواصل أو منصة، وليس حجزاً محققاً.

## مبادئ وأولويات

| الحاجة | استجابة التصميم | دليل قبول |
|---|---|---|
| من أنتم؟ | ALMAGD + شعار + بطاقات الثلاث في أول مسار قراءة | مستخدم يميز الشركة عن المنشآت |
| أي إقامة تناسبني؟ | /properties للإقامتين؛ فروق مؤكدة فقط | لا مقارنة بأسعار أو سعات ناقصة |
| كيف أتواصل؟ | CTA خاص بالمنشأة، chooser جماعي | كل نقرة توصل للرقم الصحيح |
| ماذا يقدم الكافيه؟ | قائمة نصية سهلة وأسعار IDR | لا اعتماد على صور أو PDF وحدها |
| أين المدخل؟ | عنوان + pin مثبت + directions | لا تنشيط pin تخميني |
| هل المعلومات موثوقة؟ | صور حقيقية، مواعيد وسياسات مؤكدة، badges مشروطة | لا خانات empty أو ادعاءات غير مثبتة |

الترتيب P0: وضوح النوع والوجهة، قراءة الهاتف، CTA، اتجاه اللغة، صور صحيحة. P1: مزيد من التعريف والمحتوى والأصول. صفحات /faq و/offers لا تُضاف إلى قائمة الإطلاق تلقائياً.

## نموذج التفاعل

بنية صفحات بسيطة، عنوان واحد واضح، links للأماكن و buttons للأفعال. لا اختيار تاريخ أو عدد ضيوف داخل الموقع، لا حساب ولا سلة ولا نموذج. RoomDetailDialog للصور والحقائق فقط؛ WhatsApp يحمل سياق النوع. MenuNav روابط فئات؛ الفلترة enhancement لا شرط للوصول إلى الأسعار. GalleryFilter حسب المنشأة في P0؛ Lightbox اختياري مع رابط بديل.

## المحتوى الناقص

PLACEHOLDER في التخطيط و preview فقط. الحقل غير المسموح يُخفى؛ الكتلة تختفي إذا لا محتوى صالح؛ CTA يختفي إذا لا وجهة موثوقة. المحتوى المحجوب لا يُستخدم في alt أو title أو analytics. صفحة تعتمد على blocker لا تُطلق دون تسويته أو الاستثناء الموثق المسموح في MISSING-DATA.

## التحقق مع مستخدمين

خطة جلسات مقترحة: 5–8 مشاركين يمثلون مستخدم هاتف Indonesian، زائر English، وزائر Arabic؛ العدد خطة لا بحث منفذ. مهام: اختيار إقامة، معرفة سياسة NJD، الاستفسار عن غرفة، إيجاد سعر طعام، الوصول الصحيح، تبديل اللغة. يسجل الوقت والأخطاء والفهم والتردد دون بيانات حساسة. معيار تخطيطي: ≥80% إتمام مستقل للمهام الرئيسية و 0 توجيه إلى منشأة خاطئة؛ نتائج الاختبار الحالية NOT_RUN.
