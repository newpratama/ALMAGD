# مواصفات الهاتف الدقيقة

DEC-023/027؛ tokens من [IMPLEMENTATION-CONTEXT §6](../15-AI-HANDOFF/IMPLEMENTATION-CONTEXT.md). المقاسات px تخطيطية للواجهة المستقبلية؛ لم ينفذ شيء.

## المساحات والتنقل

| العنصر | مواصفة |
|---|---|
| viewport المرجعي | 320، 360، 390، 430؛ اختبار landscape أيضاً |
| container | هامش 16 عند <480، 24 عند 480–767؛ لا تمرير أفقي للصفحة |
| header | 60 للهاتف حسب NAVIGATION، 72 desktop؛ يتوسع إذا التف النص؛ language داخل MobileNav على الهاتف |
| أهداف اللمس | ≥44×44 لكل زر ورابط تفاعلي رئيسي؛ gap مستهدف 8؛ لا ضغط نص العربية لتصغير الهدف |
| body | 16 Latin، 16 AR مع line-height 1.8؛ النص الأساسي لا يقل عن 16 |
| hero | صورة 4:5 للهاتف، نص مستقل أو scrim مضبوط؛ ارتفاع محتوى لا ثابت يقص الكلمات |
| صفوف الأسعار | الاسم يلتف، السعر يبقى وحدة واحدة؛ لا قص/ellipsis يخفي الاسم |

## FloatingWhatsApp

زر 56×56، أيقونة 24، تسمية وصول «تواصلوا مع {venue} عبر واتساب» أو «اختاروا وجهة للتواصل عبر واتساب». موضع inline-end 16، bottom 16 + safe-area. على AR ينتقل إلى الجانب المقابل حسب اتجاه الصفحة؛ الأيقونة والشعار لا يُعكسان.

في group-level صفحات Home/About/Properties/Gallery/Location/Contact/Privacy/404: يفتح WhatsAppChooser، لا رقم مؤسسي. في New Pratama/Villa NJD/Cafe/Menu: يوجه للمنشأة الصحيحة مباشرة عند عدم وجود الشريط الثابت. Gallery تبقى group حتى عند فلترة الصور؛ لا تغيير رقم الزر بصمت.

## BookingPanel الثابت للإقامات

ليس محرك حجز؛ شريط CTA على صفحات الإقامتين و Cafe عند <1024 وفق NAVIGATION. ارتفاع أساسي 64 + safe-area يتوسع عند التف النص؛ WhatsApp رئيسي 60%، وثانوي Book يفتح خيارات BookingPanel للـ OTA المعتمدة. على Cafe: WhatsApp + Menu، دون OTA. زر رئيسي حد أدنى ارتفاع 48. لا datepicker ولا سعر ولا عدّاد توافر.

الشريط ثابت في صفحات المنشآت المحددة منذ العرض، ويختفي مؤقتاً عند فتح modal/mobile menu. توفير مساحة نهاية المحتوى تساوي الارتفاع الفعلي للشريط +16 حتى لا يغطيه. **عندما الشريط موجود يُخفى FloatingWhatsApp** وفق NAVIGATION. صفحة Menu لها زر Cafe العائم دون شريط إضافي.

## طبقات وتعارضات

ترتيب مفهومي: المحتوى < header < شريط/زر CTA < consent < sheet/dialog. الأرقام التقنية تضبط لاحقاً في design tokens. عند consent banner: يدفع الزر/الشريط إلى أعلى الارتفاع الفعلي للبانر وفق NAVIGATION؛ إذا ضاقت المساحة يخفي CTA الثابت مؤقتاً، ولا يحجب خيارات consent أو Privacy. عند الكيبورد/تكبير النص لا يتراكب شريط ثابت على focused control؛ ليست هناك forms P0.

WhatsAppChooser: bottom sheet بعرض الشاشة، max ارتفاع 80% viewport المرئي، قائمة رأسية، 3 أهداف ≥48 ارتفاع؛ عنوان وإغلاق ≥44، تمرير داخلي عند الضرورة، background غير تفاعلي، Escape/زر إغلاق وعودة focus. الأرقام غير المعتمدة غير قابلة للتشغيل؛ لا زر disabled غامض في الإنتاج.

## وصول وأداء الهاتف

صور ذات أبعاد محفوظة تمنع CLS، hero image-first، لا فيديو mobile. MenuNav صف يلتف أو قائمة تمرير موضعي واضحة؛ section anchors لا تختفي تحت header. وضع landscape و zoom 200% يسمحان بتمرير المحتوى، لا تثبيت حجم sheet يقطع الأزرار. CTA وإشعارات الفلترة تصل لقارئ الشاشة. اختبار 400% reflow يعالج تثبيت الشريط بإزالته عند ضيق المساحة الفعلي.

قبول: لا overlap في 320/390 وفي Arabic، لا CTA مكرر متزامن، safe-area iOS محترم، كل focus مرئي، لا تمرير أفقي عام، وسائل التواصل تصل للجهة الصحيحة.
