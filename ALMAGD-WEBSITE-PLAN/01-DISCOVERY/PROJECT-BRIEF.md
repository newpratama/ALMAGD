| Item | Value |

| Venues | New Pratama Villa · Villa NJD · NJD Cafe (Cisarua, Puncak, Bogor) |
| Languages | Bahasa Indonesia (default), English, Arabic (DEC-012) |
| Primary conversions | WhatsApp inquiry, phone call, OTA click-out, directions |
| Stack | Astro static + Git content files + Cloudflare Pages (DEC-014–016) |
| Quality bar | Mobile-first, WCAG 2.2 AA, Core Web Vitals good, no fabricated content |

## Problem
ALMAGD has **no web presence**. Its venues exist only as OTA listings and social accounts with inconsistent names, numbers and details. Guests cannot see the group as one trustworthy operator, contact the right venue easily, or find accurate location info.

## Solution
A fast, elegant, multilingual site that presents ALMAGD as the umbrella brand, gives each venue a complete, honest page, routes every visitor to the correct WhatsApp/OTA/map in one tap, and becomes the canonical source of venue information for Google.

## Success in one sentence
A visitor on a phone in Jakarta, Riyadh or Puncak can understand what ALMAGD offers, trust it, and contact the right venue in under 30 seconds.
