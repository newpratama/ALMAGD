# NON-GOALS

The site will **not** include — and the coding model must not add:

| Non-goal | Reason |
|---|---|
| Booking engine / availability calendar / payments | DEC-001; OTAs + WhatsApp handle this |
| PMS, ERP, CRM, channel manager | Out of scope |
| Food ordering / cart / delivery | WhatsApp catalog exists; site only shows menu |
| User accounts, login, loyalty | No need |
| Contact forms, newsletter forms | DEC-019 (no backend) |
| Database, Supabase, serverless functions | DEC-015 |
| Headless CMS at launch | DEC-015 |
| Live chat widgets | Third-party JS; WhatsApp link is enough |
| Instagram/TikTok/Maps/YouTube embeds on load | DEC-020/021/022 |
| Room prices / "from Rp" | DEC-007 |
| Copied OTA reviews, fabricated testimonials | DEC-011, DEC-010 |
| Blog / news | No content owner |
| Pop-ups, auto-playing sliders, parallax | UX & performance |
| Machine-translated final copy | DEC-012 |
| Star-rating claims, "luxury", "best in Puncak" | Unverified claims |
