# التبعيات والبوابات

ترتيب T-01…62 من TASK-BREAKDOWN. انتهاء المهمة السابقة لا يكفي إذا بوابة البيانات ناقصة. التبعيات الفنية، وبيانات الإدارة، واعتماد الإطلاق أنواع منفصلة.

| التبعية | تحجب | ما يمكن متابعته مستقلاً |
|---|---|---|
| versions/static/host T-01 | إعداد config واعتماد redirects | copy وطلبات أصول |
| تحقق CONTENT-MODEL | عرض الحقائق و schema | layout dev ب markers |
| اعتماد صفحة/لغة | صفحة اللغة و hreflang/switcher | layout دون نشر ترجمة ناقصة |
| MD-12/34 والتحقق من Cafe contact | قنوات WhatsApp الفعلية | copy وتصميم الصفحات |

المسار الحرج: عقد → محتوى/لغة → مكونات → صفحات → SEO/consent/events → QA وإصلاح → بوابات → release. قد تصبح الميديا أو جواب الإدارة التبعية الحاكمة؛ لا تقدير تقويم دون مسؤولين وسعة عمل.

لا يعالج blocker بقيمة 0 أو blank أو assumed available/rights/approved. استثناء rooms هو قسم فقط حيث يسمح MISSING-DATA وبقبول المالك؛ موقع Cafe لا يصبح optional لمجرد أن layout صالح.

ترتيب الحقيقة MASTER-DECISIONS > DATA-AUDIT > SITEMAP؛ CONTENT-MODEL أعلى تفاصيل الحقول، NAVIGATION أعلى أبعاد التنقل. الاختصار في IMPLEMENTATION-CONTEXT لا يلغي التفاصيل.

قبول: التبعيات بلا دورات، النوع والمالك واضحان، والمرحلة لا تسمى VERIFIED بينما دليلها أو بوابتها المطلوبة غائبان.
