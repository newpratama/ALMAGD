# LOGO REQUIREMENTS

## Design guidance
- Mood: calm, crafted, confident; avoid crowns, domes, palm trees, gold gradients, script fonts.
- Arabic letterforms must be drawn/adjusted by a designer experienced in Arabic type (proper baseline and weight harmony with Latin).
- Should work with brass accent line motif.

## Interim rule (until logo delivered)
Header uses a **text wordmark**: "ALMAGD" in Fraunces 600, letter-spacing +0.06em, pine colour; on `/ar` pages "المجد" in IBM Plex Sans Arabic 700 followed by "ALMAGD" small. Favicon: "A" monogram in Fraunces on pine square. Must be replaced by a single component swap (`SiteHeader` logo slot) — no layout change required.
