# COLOR DIRECTION

Tokens & contrast → [COLOR-SYSTEM.md](../08-DESIGN/COLOR-SYSTEM.md).

| Colour | Hex | Meaning / link to brief |
|---|---|---|
| Pine | #1E3B32 | Puncak forests, stability, **trust**; primary brand colour |
| Tea | #4F6B4C | Tea plantations of Gunung Mas/Cisarua, **nature** |
| Tea-100 | #DCE5D6 | Soft leaf tint for calm panels |
| Mist | #F6F3EC | Morning mist, warm **hospitality** canvas |
| Stone | #ECE7DD | Natural stone/wood tones for alternating sections |
| Brass | #B8873B | "Al-Majd" — glory, warmth, lamplight; used sparingly as **accent** |
| Ink | #1A1D1B | Readable near-black text |

## Ratios
- 60% Mist/White (space) · 30% Pine/Ink (type, footer, buttons) · 8% Tea family · ≤ 2% Brass.

## Rules
- Brass is never used for body text on light backgrounds (contrast 3.2:1). Use `brass-text` #8A6420 if accent text is needed on light.
- WhatsApp green (#25D366) is **functional**, only on WhatsApp buttons, with dark text #0A2A17.
- No red except error states. No gradients except a subtle dark scrim on hero images for text legibility.
- Venue pages use the same palette (no per-venue colours at launch) to reinforce the masterbrand.
