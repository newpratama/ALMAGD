ALMAGD Biometric Sync Tool - أداة مزامنة بصمة الحضور لنظام المجد
Fingerspot Revo W-230N -> ALMAGD Supabase Cloud
مخصصة لنظام التشغيل Windows (جهاز كمبيوتر الاستقبال)
========================================================================

★ مجهزة بالكامل ومدمجة مع محرك بايثون المحمول (Portable Python) ومكتبة البصمة (zk)
★ لا تحتاج إلى تثبيت أي برامج خارجية أو إعدادات معقدة على جهاز الاستقبال!

------------------------------------------------------------------------
★ طريقة الاستخدام السريعة على كمبيوتر الاستقبال (Windows):
------------------------------------------------------------------------

1. انسخ مجلد (biometric-sync-tool) إلى كمبيوتر الاستقبال في أي مكان (مثلاً C:\almagd-sync أو سطح المكتب).
2. انقر نقرتين على ملف:
   [ تثبيت_تلقائي_مع_تشغيل_الويندوز.bat ]
   أو [ install-windows.bat ]
   (يُفضل الضغط بالزر الأيمن واختيار "تشغيل كمسؤول").

3. انتهى! 
   - ستبدأ الأداة فوراً بالعمل في خلفية الويندوز بدون أي نافذة سوداء.
   - ستعمل الأداة تلقائياً عند كل تشغيل أو إعادة تشغيل لجهاز الكمبيوتر.
   - حتى لو انقطع الإنترنت، تُحفظ البصمات في ملف محلي (attendance_cache.db)،
     وبمجرد عودة الإنترنت ترفع كافة البصمات تلقائياً إلى نظام المجد.

------------------------------------------------------------------------
★ الملفات المساعدة:
- [ ابدأ_المزامنة.bat ]: تشغيل المزامنة فوراً في الخلفية.
- [ إيقاف_المزامنة.bat ]: إيقاف المزامنة إن أردت ذلك لأي سبب.
- [ فحص_الاتصال_بالجهاز.bat ]: فحص الاتصال بجهاز البصمة والتأكد من قراءة البيانات.
- [ config.json ]: يحتوي على IP جهاز البصمة، السيريال، ومفاتيح السحابة.
